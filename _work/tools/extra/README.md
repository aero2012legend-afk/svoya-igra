# Скрипты из облачной сессии

Писались для облачного контейнера: пути `/home/user/svoya-igra` (корень игры), `/opt/aienv/bin/python` (Python с faster-whisper и demucs),
`/opt/models/whisper` (модели), `/tmp/claude-0/.../scratchpad` (рабочая папка) — перед запуском поправить под свой компьютер.

- `asr_chunks.py` — распознать голос песни кусками по 12 с (Whisper не теряет половину песни).
- `dyr_kar.py` — караоке «Дырявого плейлиста»: строчки до/после пропуска, интервалы `mute` для повторов слова.
- `chyo2.py` — караоке «Чё думали не будет?» (текст с сайта + время слов).
- `kb3.py` (+ `kb_align.py`, `kb_lyr.py`) — припевы караоке-баттла: окно, настоящий текст, время слов из трёх распознаваний.
- `lyrics_find.py` — поиск текста песни по сайтам; `asr_file.py` — распознать один файл.
- `fullcheck.mjs`, `kbtest.mjs`, `bonustest.mjs`, `contest.mjs` — проверки в браузере (Playwright).

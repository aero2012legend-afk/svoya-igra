# Задание для авторов пака «Своя игра» (день рождения Старого)

Игра — «Своя игра» на телевизоре, праздник у друзей (взрослые, с алкоголем). Именинник — **Василий, по прозвищу «Старый»** (ведущий и судья — он же). Над ним можно и нужно подшучивать.
Пак строится на **юморе с долей иронии, небольшой издёвкой и подколами**. Каждый вопрос должен быть либо смешным, либо с подвохом, либо с интересной картинкой/звуком — скучных школьных вопросов «Столица Канады?» быть не должно.

## Цены и сложность — ГЛАВНОЕ ТРЕБОВАНИЕ
- Раунд 1: 100, 200, … 1000. Раунд 2: 200, 400, … 2000. Раунд 3: 300, 600, … 3000. В каждой теме ровно 10 вопросов.
- **Сложность строго растёт с ценой**: первый вопрос темы — очевидный почти для всех, последний — трудный (но честный и решаемый для знатока). Сравнивай соседние вопросы попарно: следующий всегда труднее предыдущего. Раунд 2 в целом труднее раунда 1, раунд 3 — труднее раунда 2.
- Вопросы №8, №9, №10 в теме — это «🥉 бронза», «🥈 серебро», «🥇 золото». Это самые сильные вопросы темы: трудные, эффектные, запоминающиеся.
- Целевая аудитория: русские ребята примерно 20–35 лет (детство в 2000-х), смотрели мультики 90-х/2000-х, играли в игры 2000-х–2010-х, сидят в интернете.

## Факты
- Все факты и ответы должны быть **правильными**. Если не уверен — не используй. Ответ однозначный (или перечисли допустимые варианты в `a`, например «Шрек (принимается: Shrek)»).
- Картинка обязана реально соответствовать ответу — **всегда смотри скачанную/нарисованную картинку через Read** перед тем как её взять.

## Формат результата
Положи файл `_work/content/<slug>.json` (UTF-8, валидный JSON):
```json
{ "themes": [
  { "round": 1, "name": "Кинчики", "questions": [ {вопрос}, … 10 штук … ] },
  { "round": 2, "name": "Кинчики", "questions": [ … ] }
] }
```
Поля вопроса:
| поле | что это |
|---|---|
| `price` | цена (см. выше) |
| `q` | текст вопроса на экране (коротко, с юмором; до ~160 символов, если есть картинка — короче) |
| `a` | правильный ответ (виден после «Показать ответ») |
| `c` | (необязательно, но очень желательно) шутка/подкол/интересный факт, показывается под ответом |
| `hint` | подсказка за «подкуп судьи», уходит игроку на телефон (не выдаёт ответ целиком) |
| `img` | картинка к вопросу: `media/img/<slug>/<файл>` |
| `fx` | эффект для картинки (игра применит сама, оригинал покажет при ответе): `blur` — сильно размыто; `deblur` — размытие постепенно уходит, пока идёт таймер; `pixel` — крупные пиксели; `zoom` — показан крупно только кусочек (нужно `area`); `crop` — видно только окошко (нужно `area`), остальное чёрное; `tiles` — картинка порезана на квадраты и перемешана; `silhouette` — чёрный силуэт; `negative` — негатив; `mirror` — зеркально |
| `area` | для `zoom`/`crop`: `[x, y, w, h]` в процентах от картинки (0–100), например глаза на портрете `[30, 35, 40, 15]` |
| `aimg` | (необязательно) другая картинка, которая показывается при ответе (например, полный постер) |
| `audio` / `video` | звук или видео: `media/music/<slug>/<файл>.mp3` (видео `media/video/<slug>/…mp4`) |
| `start`, `end` | откуда и докуда играть файл (секунды). Для «пропущенного слова» `end` — момент ПЕРЕД пропущенным словом: музыка там остановится |
| `aend` | после «Показать ответ» звук продолжит играть с `end` до `aend` (чтобы все услышали правильное слово) |
| `kar` | караоке: массив `[[секунда, "строчка текста"], …]` по времени файла; игра показывает строчки синхронно с музыкой. Строчки после `end` игра скрывает до ответа. Пропущенное слово в строчке пиши как `___` |
| `type` | НЕ ставь `cat`/`auction`/`trap`/`bonus` — спецклетки расставит сборщик. Исключение: `mashup` (см. ниже) |

Если в тексте нужен апостроф — в JSON это не проблема. Кавычки «ёлочки».

## Картинки
- В большинстве вопросов должна быть картинка (кроме чисто звуковых/видео). Играй с подачей: размытие, кусочек, перемешанные квадраты, силуэт, негатив — чтобы было не слишком просто. Чем дороже вопрос, тем хитрее подача.
- Фото: JPEG, длинная сторона до 1280 px, качество ~82 (`python3 -c "from PIL import Image; …"`). Рисунки/схемы/ребусы: WebP или PNG (до 1280 px). Один файл ≤ 400 КБ, лучше меньше.
- Складывай в `media/img/<slug>/` с понятными именами, например `media/img/kinchiki/r1_300_matrix.jpg`.
- **На картинке-вопросе не должно быть ответа** (названий, подписей, логотипов с названием, водяных знаков с названием фильма). Если на кадре есть надпись — обрежь или закрась.
- Инструменты (запускай из корня репозитория `/home/user/svoya-igra`):
  - Поиск фото в интернете: `python3 _work/tools/imgsearch.py "запрос" /tmp/<slug>/s1 8 x` → скачает до 8 кандидатов и лист превью `…_sheet.jpg` — посмотри его через Read, выбери, потом обрежь/сожми через PIL и сохрани в `media/img/<slug>/`. Запросы можно на русском и английском («кадр из фильма Матрица Нео ложка», «Jagermeister bottle»).
  - Нарисовать нейросетью (SD-Turbo, на CPU ~20 с на картинку, очередь общая): `python3 _work/tools/sd.py "english prompt" /tmp/<slug>/g1 4` → `g1_1.png…`, превью `g1_sheet.jpg`. Хорошо выходят детские рисунки («childs crayon drawing of …, scribbles on white paper»), карикатуры, мультяшные сцены. Плохо — буквы, логотипы, точные лица. Не заказывай больше 4–6 картинок за раз.
  - Сверстать картинку из HTML/SVG/эмодзи (ребусы, схемы, «вырезки из правил», переписки, мемные шаблоны): напиши HTML-файл и `node _work/tools/render.mjs file.html out.png 1280 720` (эмодзи — Noto Color Emoji, шрифты — системные sans-serif, DejaVu). Детские рисунки руками удобно делать SVG-путями с «дрожанием» и толстыми цветными штрихами.
  - Можно комбинировать: нейро-картинка + надписи/стрелки поверх через HTML.

## Звук и видео (только для тем, где это нужно)
- YouTube отсюда заблокирован. Работает SoundCloud: `/opt/aienv/bin/yt-dlp -x --audio-format mp3 --no-playlist -o "/tmp/<slug>/%(title)s.%(ext)s" "scsearch5:запрос"` (можно сначала посмотреть список: `--flat-playlist --print "%(title)s | %(uploader)s | %(duration)s | %(webpage_url)s" "scsearch8:запрос"` и скачать нужный URL). Следи, чтобы это был оригинал, а не кавер/ремикс/ускоренная версия.
- Распознать слова с точным временем: `/opt/aienv/bin/python _work/tools/audio_words.py song.mp3 60 120 --prompt "начало текста песни"` (добавь `--vocals`, если музыка громкая). Медленно (≈0.5–1 мин на минуту звука) — вырезай нужный кусок.
- Вырезать фрагмент: `bash _work/tools/cut_audio.sh in.mp3 _private/media/music/<slug>/имя.mp3 START END`. После нарезки время в файле начинается с 0 — пересчитай `start`/`end`/`aend`/`kar` под новый файл.
- **Музыка и видео защищены авторским правом и НЕ кладутся в публичный репозиторий**: сохраняй их только в `_private/media/music/<slug>/` (или `_private/media/video/<slug>/`), а в вопросе пиши путь `media/music/<slug>/имя.mp3`. Для каждого файла добавь запись в `_work/audio/<slug>.json`: `[{"file": "media/music/<slug>/имя.mp3", "source": "URL", "title": "что это", "cut": [START, END]}]` — чтобы файл можно было пересоздать.
- Если звук найти не удалось — не выдумывай, лучше замени вопрос другим форматом (картинка/описание) или запиши в `_work/audio/<slug>.json` запись с `"missing": true` и подробным описанием, какой фрагмент нужен.

## Тон
- Юмор, ирония, подколы — в основном над игроками и ситуацией. Старого упоминай не больше 2 раз на тему.
- Запрещено: упоминать работу Старого (прошлую — повар, кухня; нынешнюю — транспортная безопасность, досмотр, рамка), историю с Касперским. Фанта — максимум раз на тему (лучше пиво или без напитков). Формулировки вопросов — живые, разговорные («Что за фильм, где мужик в плаще уворачивается от пуль, как ты от ответственности?»).
- Уровень жёсткости по умолчанию 3–6 из 10; где в задании темы сказано «жёстко» — 4–8 из 10 (мат — редко и к месту, без оскорблений по национальности/внешности/болезням, без политики).
- Подсказки (`hint`) тоже могут быть смешными, но должны реально помогать.

## Самопроверка перед сдачей
1. 10 вопросов на тему, цены правильные, сложность растёт — перечитай тему сверху вниз.
2. Все файлы из `img`/`aimg`/`pics` существуют (`ls`), открываются, на картинке нет ответа.
3. `python3 -c "import json; json.load(open('_work/content/<slug>.json'))"` — JSON валиден.
4. В конце верни краткий отчёт: сколько вопросов, сколько с картинками/звуком, какие звуки не нашлись.

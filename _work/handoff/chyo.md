# Handoff: тема «Чё думали не будет?», раунд 3 (slug chyo)

Файл темы: `_work/content/chyo.json` (одна тема, round 3, name «Чё думали не будет?», цены 300…3000).
Аудио-реестр: `_work/audio/chyo.json`. Звук: `_private/media/music/chyo/r3_<цена>_<имя>.mp3`. Картинки: `media/img/chyo/r3_<цена>_<что>.jpg`.
Рабочая папка: `/tmp/chyo/` (может пропасть). Помощники в `/tmp/chyo/tools/`: mkaudio.py (нарезка под −15 LUFS как restore_audio.py), regadd.py (запись в реестр), putq.py (запись вопроса в JSON), env.py (огибающая громкости: `env.py файл от до мс`), dm.py (поиск Dailymotion), sc.sh (поиск SoundCloud), qNNN.py (скрипт записи вопроса — образец).
Механика: русский опенинг, музыка стоп на `end` перед пропущенным словом, `aend` — конец доигрывания. В kar: максимум 2 короткие строки до пропуска + строка с `___`. ТЕКСТЫ ПЕСЕН НЕ ВЫПИСЫВАТЬ (фильтр) — в записке только названия мультфильмов, тайминги и источники.
Whisper: окно ≈ 8–20 с считается ~25–60 с; первый запуск долгий (загрузка модели). `--vocals` — только если музыка мешает.

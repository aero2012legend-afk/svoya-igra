Файл темы: `_work/content/citaty.json` (одна тема, round 3, name «Цитаты для ОЛДОВ», цены 300…3000, 10 вопросов).
Запись вопроса: `python3 -c "import sys; sys.path.insert(0,'/home/user/svoya-igra/_work/handoff'); from citaty_put import put; put({...})"` (заменяет вопрос с той же ценой, сортирует по цене).
Картинки: `media/img/citaty/r3_<цена>_<что>.jpg` (≤400 КБ). Звук: только `_private/media/music/citaty/r3_*.mp3` (в вопросе путь `media/music/citaty/r3_*.mp3`), записи — `_work/audio/citaty.json` (file, source, title, cut, gain_db, ffmpeg); создавать через `restore_audio.make` (образец — /tmp/kinchiki_r3/tools/mk.py: сделать свой /tmp/citaty/tools/mk.py с путями citaty).
Временные файлы: `/tmp/citaty/` (tools/wq.py и wqmulti.py — скачивают страницы ru.wikiquote.org в /tmp/citaty/wq/*.txt; API Викицитатника с этого IP блокируется, а обычные страницы /wiki/… открываются с User-Agent браузера; ru.wikipedia.org отвечает 429 — реже).
Запреты именинника: ни слова про его работу (повар/кухня; транспортная безопасность/досмотр/рамка/ТАМОЖНЯ лучше тоже не брать), никакого Касперского, Фанта ≤ 1 раза (лучше нет), «Старый» ≤ 2 раз на тему. Цитаты — только короткие фразы, без длинных кусков текстов/сценариев.
Занятые в других темах фильмы (не повторять): Кинчики р1–р3 — Титаник, Гарри Поттер, Властелин колец («Ты не пройдёшь!»), Пираты Карибского моря, Побег из Шоушенка, Брат 2, Ёлки, Бумер, Криминальное чтиво, Реквием по мечте, Матрица, Терминатор 2, Холоп, Назад в будущее, Гладиатор, Жмурки, Интерстеллар, Начало, Дурак, Драйв, Один дома, Иван Васильевич меняет профессию («Я требую продолжения банкета!»), Особенности национальной охоты, Крёстный отец, Оппенгеймер, Леон, Молчание ягнят, Кин-дза-дза!, Парк Юрского периода, Бегущий по лезвию.

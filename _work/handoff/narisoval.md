## Как рисуем
Нейросеть (sd.py) не годится (очередь ~8 мин на 4 картинки, слишком красиво, не те предметы). Рисуем сами:
генератор SVG «детских каракулей» — `_work/handoff/narisoval_kid.py` (дрожащие толстые штрихи, зигзаг-закраска, восковое зерно);
сцены — `_work/handoff/scenes/s<цена>.py` (запуск: `cd /home/user/svoya-igra && python3 _work/handoff/scenes/s2700.py` → /tmp/narisoval/<цена>.png и webp в media/img/narisoval/);
вопрос в JSON дописывает/заменяет `_work/handoff/narisoval_save.py` (`save_q({...})` — заменяет вопрос с той же ценой).
Картинки без надписей; на 2700 нет листьев (слово из названия не рисуем).

## Итоговая раскладка (цена — песня — что нарисовано — факты для c)
Факты проверены по ru.wikipedia / страницам с текстами (счётчики слов, тексты не копируем).
- 300 — Крокодил Гена (поёт В. Ферапонтов) — «Песенка Крокодила Гены» («Пусть бегут неуклюже»), «Чебурашка» (1971). Рисунок: крокодил в котелке с гармошкой, голубой вертолёт с волшебником, сыплющиеся эскимо, лужа с пешеходом. r3_300_gena.webp. («Голубой вагон» — другой мультфильм, «Шапокляк».)
- 600 — Аида Ведищева — «Песенка о медведях» («Кавказская пленница», 1967). Рисунок: земной шар с красно-белой осью, два медведя спинами к ней, снежинки. r3_600_medvedi.webp.
- 900 — Алла Пугачёва — «Миллион алых роз» (офиц. «Миллион роз»). Рисунок: дом с женщиной в окне, художник с палитрой и мольберт, домик, море красных цветов. r3_900_rozy.webp.
- 1200 — Высоцкий — «Кони привередливые». Рисунок: три коня вдоль обрыва, возница в санях с кнутом, туман над пропастью. r3_1200_koni.webp.
- 1500 — Сплин — «Орбит без сахара» («Гранатовый альбом», 1998). Рисунок: автоответчик на столике, пачка жвачки с планетой-орбитой, розовый пузырь, холодильник. r3_1500_orbit.webp (scenes/s1500.py).
- 1800 — Король и Шут — «Лесник». Рисунок: ночь, избушка, лесник с ружьём, путник с рюкзаком, воющие волки. r3_1800_lesnik.webp (scenes/s1800.py).
- 2100 — Ленинград — «Экспонат» (2016). Рисунок: картина с подсолнухами, театр с колоннами, туфля на шпильке с красной подошвой. r3_2100_eksponat.webp.
- 2400 (бронза) — Кино — «Группа крови». Рисунок: мягкое кресло, клетчатый плед, пистолет с красным спуском, сапоги в звёздной пыли. r3_2400_gruppa.webp.
- 2700 (серебро) — ДДТ — «Что такое осень» (Шевчук, альбом «Актриса Весна», 1992; написана в конце сентября 1991 на Никольском кладбище Александро-Невской лавры; 2-е место в «100 лучших песен XX века» Нашего радио; Муратов сперва отказывался играть «эту попсу»). Рисунок: два горящих корабля в сером небе, цепь с порванным звеном на ветру, лужа с отражением неба и птицами, камни. r3_2700_osen.webp (scenes/s2700.py). В тексте песни проверено: «в небе жгут корабли», небо под ногами/лужи/птицы/облака, камни, ветер и рваные цепи.
- 3000 (золото) — Аквариум / БГ — «Город золотой» (слова Волохонского, музыка Вавилова; в «Ассе», 1988). Рисунок: голубое небо, яркая звезда, золотая арка-ворота, огнегривый лев, синий вол в глазах, золотой орёл. r3_3000_gorod.webp.

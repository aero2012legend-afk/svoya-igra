# Папка для своих файлов

Сюда можно положить музыку, видео, картинки и свои звуковые эффекты. **Список всех нужных файлов с подсказками — в [СПИСОК.md](СПИСОК.md).**

- Музыка к вопросам — папка `music`, видео — папка `video` (имена файлов — как в `questions.js`).
- Картинка к вопросу: допиши к вопросу `img: 'media/имя-файла.jpg'`.
- Свой звук вместо встроенного: в разделе `sounds` файла `questions.js`, например `correct: 'media/ura.mp3'`.
- Песни для танцевального баттла: папка `dance` и список `danceSongs` в `questions.js`.

Файлы можно и не загружать на сайт: держи их в папке на компьютере и выбери её в лобби кнопкой «📁 Папка с музыкой и видео».

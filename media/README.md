# Папка для своих файлов

Сюда можно положить картинки, звуки и видео для вопросов, а также свои звуковые эффекты.

- Картинка к вопросу: в `questions.js` допиши к вопросу `img: 'media/имя-файла.jpg'`
- Звук или видео к вопросу: `audio: 'media/песня.mp3'` или `video: 'media/ролик.mp4'`
- Свой звук вместо встроенного: в разделе `sounds` файла `questions.js`, например `correct: 'media/ura.mp3'`

Загрузить файл на GitHub: открой эту папку → **Add file → Upload files**.

# Своя игра — памятка для Claude

Игра «Своя игра» на день рождения Василия (32 года; он же ведущий). ТВ — `index.html`, телефоны гостей — `play.html`,
пульт ведущего — `pult.html`. Чистый HTML/CSS/JS, без сборщиков. Отвечать владельцу — по-русски, коротко.

## Запуск
- `python server.py` (или «Запустить игру.bat») — раздаёт игру, `/__lan` (IP для QR) и мини-брокер MQTT по WebSocket `/mqtt`.
  Телефоны подключаются только по Wi-Fi к этому компьютеру, интернет не нужен.
- Музыка/видео с авторскими правами лежат в `_private/media/` (не в git); `server.py` отдаёт их как `media/...`.
  Архив для гостей-игроков: `python _work/tools/media_pack.py --zip svoya-igra-media.zip`.

## Устройство
- `js/game.js` — вся логика ТВ (табло, вопросы, конкурсы, караоке, оверлеи); `js/play.js` — телефон; `js/net.js` — связь
  (локальный режим: http + localhost/IPv4/.local → `ws://host/mqtt`); `js/sound.js`, `js/fx.js`, `js/bg.js` (WebGL-небо и погода).
- Отладка в браузере: `window.__svi` (G, force.con = 'id' — принудительный конкурс, act, reveal …).
- `questions.js` **не править руками** — собирается: `python _work/tools/build.py` из `_work/content/*.json`
  (раскладка тем по раундам и спецклетки — в build.py; `karbattle.json` — припевы караоке-баттла).
- Формат вопросов и требования — `_work/SPEC.md`; правила содержания — `_work/AGENT_RULES.md` (обязательно прочитать).
- Источники звуков для пересоздания — `_work/audio/*.json`; пересоздать: `python _work/tools/restore_audio.py`
  (нужны ffmpeg, yt-dlp, demucs; для караоке — faster-whisper).
- `_work/tools/extra/` — скрипты из облачной сессии (распознавание кусками, караоке «Дырявого плейлиста», «Чё думали»,
  караоке-баттл, тесты Playwright). Пути в них облачные (`/home/user/svoya-igra`, `/opt/aienv`, scratchpad) — поправить перед запуском.

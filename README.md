# 🎂 Своя игра — на день рождения

Игра в стиле «Своей игры» для телевизора. Гости играют со своих телефонов: сканируют QR-код и жмут большую кнопку.

**Играть:** https://aero2012legend-afk.github.io/svoya-igra/

## Как запустить на празднике

1. Подключи компьютер к телевизору, открой ссылку выше в Chrome или Edge, нажми **F** — полный экран.
2. Нажми «Начать». На экране появится QR-код. Гости наводят на него камеру телефона, вводят имя и сразу появляются в списке.
   Кто без телефона — добавь кнопкой «＋ Игрок без телефона».
3. Выбери «Каждый за себя» или «Команды», время на вопрос и цену подкупа, затем «▶ Начать игру».
4. **Пульт ведущего:** в лобби нажми «🔑 Пульт ведущего» и отсканируй код своим телефоном (пока никто не видит).
   На пульте — ответ на текущий вопрос, подсказка и кнопки «Верно / Неверно».

Счёт сохраняется сам: если случайно закрыл вкладку, открой снова и нажми «Продолжить игру».

## Управление (клавиатура)

| Клавиша | Что делает |
|---|---|
| Пробел | старт / пауза таймера, бросить монетку, пропустить анимацию |
| Enter | верно |
| Backspace | неверно |
| A | показать ответ |
| → | дальше (к табло, закрыть торги, следующий шаг финала) |
| 1 … 9, 0 | назначить отвечающего вручную |
| Ctrl + Z | отменить последнее действие |
| F / M / H | полный экран / звук / подсказка по клавишам |

Клик по карточке игрока внизу — меню: отвечает, выбирает вопрос, ±100, изменить счёт, переименовать.

## Правила

- **Обычный вопрос.** Вопрос появляется на экране, через секунду запускается таймер. Кто первым нажал кнопку на телефоне — отвечает.
  Верно — плюс цена вопроса, и он выбирает следующий. Неверно — минус цена, кнопки снова открываются для остальных.
  Нажал раньше времени — фальстарт, кнопка блокируется на 1,5 секунды.
- **Подкупить судью** — кнопка на телефоне во время вопроса. Стоит 50% цены вопроса (меняется в настройках).
  Подсказка из вопроса тайно приходит на телефон игрока. Если подсказки в вопросе нет, судья шепчет её сам.
- **🐱 Кот в мешке.** Вопрос нужно отдать другому игроку. Отвечает только он.
- **🔨 Аукцион.** Игроки торгуются с телефонов, побеждает самая высокая ставка. Ва-банк — все свои очки.
- **⚠ Ловушка.** Бросаем монетку: решка — пронесло, орёл — рулетка выбирает событие для того, кто выбрал вопрос:
  налоговая проверка (минус от 50 до 1000), «уговори судью» (30 секунд на уговоры), правда или действие,
  заморозка кнопки, казино (удвоить или потерять), щедрость (подари очки), двойная ставка, рокировка (обмен очками), карманник (кража у лидера).
  После события вопрос играется как обычно.
- **Финал.** Играют все, у кого счёт больше нуля. Ставки и ответы — тайно с телефонов. Ведущий открывает ответы по одному.

## Как поменять вопросы

Все вопросы лежат в файле [`questions.js`](questions.js). На GitHub открой его, нажми карандаш ✏️, поменяй тексты в кавычках и нажми **Commit changes**.
Через пару минут игра обновится. Там же — карточки для «Правды или действия» и название игры.

⚠ Репозиторий публичный, поэтому вопросы может прочитать любой, кто его найдёт. Если хочешь спрятать настоящие вопросы:
скачай проект (зелёная кнопка **Code → Download ZIP**), поменяй `questions.js` у себя на компьютере и открой `index.html` из папки.
Телефоны гостей всё равно подключатся через сайт.

## Свои звуки и картинки

Положи файлы в папку `media` и пропиши их в `questions.js`: картинка к вопросу — `img: 'media/kartinka.jpg'`,
свой звук вместо встроенного — в разделе `sounds`, например `correct: 'media/correct.mp3'`.

## Связь с телефонами

- **Лучше всего — один Wi-Fi.** Если телефон и компьютер в одной сети, они соединяются напрямую: быстро и без зарубежных серверов.
  В лобби у игрока будет написано «напрямую по Wi-Fi 📶», а точка у его карточки станет голубой. Попроси гостей подключиться к домашнему Wi-Fi.
- Если напрямую не получилось (телефон на мобильном интернете), связь идёт через бесплатный открытый сервер.
  Из России такие соединения «замерзают» примерно после 16 КБ данных, поэтому игра сама незаметно открывает новое соединение заранее.
- Если в лобби не горит «● Связь есть», игра сама попробует другой сервер. Можно переключить вручную: меню ☰ → «Другой сервер связи»
  (гостям нужно заново отсканировать QR).
- Если на телефоне появилась красная полоска — нажми на неё, страница обновится, очки сохранятся.
- Без связи игра всё равно работает: отвечающего можно выбрать кликом по карточке или цифрой на клавиатуре.
